# Troubleshooting: Ribbon Icons не появляются

## 🔍 Возможные причины

### 1. ⚙️ Ribbon Bar скрыт в настройках Obsidian

**Проверка:**
1. Откройте **Settings** (⚙️)
2. Перейдите в **Appearance**
3. Найдите опцию **Show ribbon** или **Ribbon**
4. Убедитесь, что она **включена** ✅

**Альтернатива:**
- Используйте комбинацию клавиш для переключения Ribbon: обычно это настраивается в **Hotkeys**

### 2. 🎨 Тема скрывает Ribbon

Некоторые темы могут скрывать или изменять внешний вид Ribbon:
- Попробуйте переключиться на стандартную тему
- Проверьте CSS snippets - они могут скрывать ribbon

### 3. 📱 Мобильная версия

На мобильных устройствах Ribbon может быть скрыт или работать по-другому.

### 4. 🔄 Кэш плагина

**Решение:**
1. Закройте Obsidian полностью
2. Удалите файл `main.js` из папки плагина
3. Пересоберите плагин: `npm run build`
4. Перезапустите Obsidian

### 5. ✅ Использование команд вместо иконок

Если ribbon icons не появляются, используйте **Command Palette**:

1. Нажмите `Cmd/Ctrl + P`
2. Введите название команды:
   - **"Создать лог тренировки"**
   - **"Открыть упражнения"**
   - **"Обновить кэш упражнений"**
   - **"Обновить файлы упражнений"**

## 🛠️ Отладка

### Проверка в консоли

После перезапуска плагина проверьте в консоли (Cmd/Ctrl+Shift+I):

```
[Main] 📅 Добавление ribbon icon для создания лога...
[Main] 📅 Ribbon icon создан: успешно
[Main] 💪 Добавление ribbon icon для упражнений...
[Main] 💪 Ribbon icon создан: успешно
```

Если видите `"не удалось"` - это указывает на проблему с API Obsidian.

### Проверка доступности API

В консоли выполните:
```javascript
// Проверка, что плагин загружен
app.plugins.plugins['workout-tracker']

// Проверка ribbon элементов
app.workspace.leftRibbon.ribbonActionsEl.children
```

### Проверка иконок

Попробуйте другие стандартные иконки:
```typescript
this.addRibbonIcon('gear', 'Тест', () => { });
this.addRibbonIcon('star', 'Тест', () => { });
this.addRibbonIcon('checkmark', 'Тест', () => { });
```

## 📋 Где находится Ribbon Bar?

**Desktop:**
- **Слева:** Вертикальная панель с иконками
- Обычно содержит: File explorer, Search, Graph view и др.

**Расположение:**
```
┌─────────────────────────────────┐
│ [📁] ← Ribbon Bar (слева)       │
│ [🔍]                            │
│ [🔗]                            │
│ [➕] ← Ваша иконка создания лога│
│ [📋] ← Ваша иконка упражнений   │
└─────────────────────────────────┘
```

## ✅ Что делать дальше

1. **Проверьте Settings → Appearance → Show ribbon**
2. **Перезапустите Obsidian** и проверьте консоль
3. **Используйте Command Palette** (Cmd/Ctrl+P) как альтернативу
4. Если проблема сохраняется, отправьте логи из консоли
