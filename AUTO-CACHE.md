# Автоматическое кэширование логов

## ✅ Кэширование происходит автоматически в следующих случаях:

### 1. **При запуске Obsidian** 🚀
- Когда вы открываете Obsidian, плагин загружается
- Автоматически проверяются новые логи
- Кэшируются только **незакэшированные** файлы
- **Уведомление**: `✅ Закэшировано X логов!` (только если есть новые)

### 2. **При перезапуске плагина** 🔄
- Settings → Community plugins → Workout Tracker → Disable/Enable
- Срабатывает то же самое, что и при запуске Obsidian

### 3. **При открытии файла упражнения** 📖
- Открываете любой файл из папки `Exercises/`
- Плагин проверяет наличие новых логов
- Кэширует их **перед** обновлением содержимого файла
- **Без уведомления** (только в консоли)

### 4. **При создании нового лога** 📝
- Создаёте новый лог через кнопку или команду
- Автоматически кэшируется
- **Без уведомления** (только в консоли)

### 5. **Вручную через команду** 💪
- Command Palette (`Cmd/Ctrl + P`) → "Обновить кэш упражнений"
- **Уведомление**: `✅ Закэшировано X логов!` или `✅ Все логи уже закэшированы!`

### 6. **Вручную через настройки** ⚙️
- Settings → Workout Tracker → Кэширование логов → **Обновить кэш**
- **Уведомление**: `✅ Закэшировано X логов!` или `✅ Все логи уже закэшированы!`

---

## 🔍 Как работает проверка на уже закэшированные логи?

Кэш хранит список обработанных файлов в `cachedFiles[]`:

```json
{
  "cachedFiles": [
    "Workout/Logs/2025-10-09-Monday.md",
    "Workout/Logs/2025-10-08-Home.md",
    "Workout/Logs/2025-10-07-Home.md"
  ]
}
```

При каждом запуске `rebuildCache`:
1. **Получает все логи** из папки `Logs/`
2. **Фильтрует** только те, которых **нет** в `cachedFiles[]`
3. **Парсит** только новые файлы
4. **Добавляет** их в `cachedFiles[]`
5. **Сохраняет** кэш

**Результат**: Каждый лог парсится **только один раз**! ⚡

## 📊 Консольные логи

В Developer Console (`Cmd/Ctrl + Shift + I`) вы увидите:

```
[ExerciseCache] Начинаем rebuild кэша...
[ExerciseCache] Найдено файлов логов: 15
[ExerciseCache] Уже закэшировано файлов: 12
[ExerciseCache] ⚡ Новых файлов для кэширования: 3
[ExerciseCache] Список новых файлов: 2025-10-09-Monday.md, 2025-10-09-Wednesday.md, 2025-10-09-Friday.md
[ExerciseCache] Файл обработан: Workout/Logs/2025-10-09-Monday.md
[ExerciseCache] Добавлено: Жим ног дата: 2025-10-09 подходов: 2
...
[ExerciseCache] ✅ Кэширование завершено, сохранено
[Main] Закэшировано 3 новых логов при запуске
```

Если все логи уже закэшированы:
```
[ExerciseCache] Начинаем rebuild кэша...
[ExerciseCache] Найдено файлов логов: 15
[ExerciseCache] Уже закэшировано файлов: 15
[ExerciseCache] ✅ Нет новых файлов для кэширования
```

## 🎯 Преимущества:

- ✅ **Автоматически** — не нужно помнить про кэширование
- ✅ **Эффективно** — каждый файл парсится только один раз
- ✅ **Быстро** — проверка занимает миллисекунды
- ✅ **Прозрачно** — все действия логируются
- ✅ **Гибко** — можно обновить вручную в любой момент

---

## ⚠️ Важно:

### Если вы вручную изменили старый лог:
1. Settings → Workout Tracker → **Очистить кэш**
2. Settings → Workout Tracker → **Обновить кэш**

Или используйте команду "Обновить кэш упражнений" из Command Palette.

---

## 🧪 Как протестировать:

1. **Создайте новый лог** → откройте консоль → должно быть "Закэшировано 1 новых логов"
2. **Перезапустите плагин** → должно быть "✅ Нет новых файлов для кэширования"
3. **Откройте файл упражнения** → консоль должна показать проверку кэша
4. **Создайте ещё один лог** → откройте упражнение → новый лог должен быть закэширован
