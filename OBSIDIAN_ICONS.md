# Иконки Obsidian для Ribbon

## Используемые иконки в плагине

| Иконка | Название | Использование |
|--------|----------|---------------|
| `calendar-days` | 📅 | Создать лог тренировки |
| `dumbbell` | � | Список упражнений |

**Примечание:** Иконка `dumbbell` доступна в современных версиях Lucide Icons (используется в Obsidian). Если она не отображается в вашей версии Obsidian, используйте альтернативные варианты ниже.

## Популярные иконки Obsidian (Lucide Icons)

Obsidian использует библиотеку Lucide Icons. Вот список популярных иконок:

### Действия
- `plus` - Плюс
- `plus-with-circle` - Плюс в кружке
- `minus` - Минус
- `x` - Закрыть
- `check` - Галочка
- `chevron-right` - Стрелка вправо
- `chevron-left` - Стрелка влево
- `arrow-right` - Стрелка вправо
- `arrow-left` - Стрелка влево

### Файлы и папки
- `file` - Файл
- `folder` - Папка
- `folder-open` - Открытая папка
- `file-text` - Текстовый файл
- `trash` - Корзина
- `archive` - Архив

### Редактирование
- `edit` - Редактировать
- `pencil` - Карандаш
- `save` - Сохранить
- `copy` - Копировать
- `clipboard` - Буфер обмена

### Навигация
- `home` - Домой
- `search` - Поиск
- `settings` - Настройки
- `star` - Звезда
- `bookmark` - Закладка
- `link` - Ссылка

### Медиа
- `image` - Изображение
- `video` - Видео
- `music` - Музыка
- `mic` - Микрофон

### Списки
- `list` - Список
- `list-ordered` - Нумерованный список
- `check-square` - Чекбокс
- `calendar` - Календарь

### Информация
- `info` - Информация
- `alert-circle` - Предупреждение
- `help-circle` - Помощь
- `alert-triangle` - Внимание

### Тренировки (альтернативы для 'dumbbell')
- `activity` - Активность
- `target` - Цель
- `trending-up` - График роста
- `bar-chart` - Столбчатая диаграмма
- `zap` - Молния (энергия)

### Календарь
- `calendar` - Календарь
- `calendar-days` - Календарь с днями ⭐ (используется в плагине)
- `clock` - Часы

### Тренировки
- `dumbbell` - Гантель ⭐ (используется в плагине, требует Obsidian 1.4+)
- `activity` - Активность (альтернатива если dumbbell не работает)
- `target` - Цель (альтернатива)
- `trending-up` - График роста (альтернатива)
- `bar-chart` - Столбчатая диаграмма (альтернатива)
- `zap` - Молния (альтернатива)

## Примеры использования

```typescript
// Используемые в плагине
this.addRibbonIcon('calendar-days', 'Создать лог тренировки', () => { });
this.addRibbonIcon('dumbbell', 'Упражнения', () => { });

// Альтернативные варианты если dumbbell не поддерживается
this.addRibbonIcon('activity', 'Упражнения', () => { });
this.addRibbonIcon('trending-up', 'Прогресс', () => { });
this.addRibbonIcon('zap', 'Быстрая тренировка', () => { });
```

## Проверка доступных иконок

Чтобы увидеть все доступные иконки в Obsidian:

1. Откройте Developer Console (Cmd+Option+I)
2. Выполните:
```javascript
Object.keys(window.app.internalPlugins.plugins['switcher'].instance.iconList)
```

Или посмотрите документацию Lucide Icons:
https://lucide.dev/icons/

## Рекомендации

- Используйте простые, понятные иконки
- Избегайте слишком специфичных иконок (например, 'dumbbell' может не быть в стандартном наборе)
- Для тренировок лучше использовать универсальные иконки: `activity`, `trending-up`, `zap`
- Всегда указывайте понятный tooltip (второй параметр `addRibbonIcon`)
