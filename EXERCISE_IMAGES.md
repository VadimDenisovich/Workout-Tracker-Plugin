# Изображения упражнений

## Обзор

Плагин автоматически собирает изображения упражнений из файлов логов тренировок и отображает их в файлах упражнений перед графиком прогресса.

## Формат в логах

В файлах логов изображения должны быть размещены **непосредственно над** заголовком 3-го уровня с названием упражнения:

```markdown
![[Pasted image 20251108104622.png|400]]
### [[Сгибание рук с гантелями сидя]]
Подход 1: _ кг × _ раз  
Подход 2: _ кг × _ раз  

{{exercise:Сгибание рук с гантелями сидя}}
```

**Важно:**
- Изображение размещается на строке **перед** заголовком `###`
- Между изображением и заголовком может быть до 2 пустых строк
- Формат изображения: `![[имя_файла.png|размер]]` или `![[имя_файла.png]]`
- Если изображения нет, график отображается без изображения

## Обновление метаданных

### Через настройки плагина

1. Откройте **Settings → Workout Tracker**
2. Найдите секцию **"Метаданные упражнений"**
3. Нажмите кнопку **"Обновить метаданные"**

Плагин выполнит:
- ✅ Синхронизацию списка упражнений с папкой `Exercises/`
- ✅ Сканирование всех логов в папке `Logs/`
- ✅ Поиск и сохранение изображений для каждого упражнения
- ✅ Обновление файла `exercise-metadata.json`

### Через командную панель

1. Откройте командную панель (`Cmd/Ctrl + P`)
2. Найдите команду **"Обновить метаданные упражнений (изображения и hasWeight)"**
3. Выполните команду

## Хранение данных

Изображения сохраняются в файле `exercise-metadata.json`:

```json
{
  "version": "1.0.0",
  "exercises": {
    "Сгибание рук с гантелями сидя": {
      "name": "Сгибание рук с гантелями сидя",
      "hasWeight": true,
      "imageLink": "![[Pasted image 20251108104622.png|400]]"
    }
  }
}
```

## Отображение в файлах упражнений

После обновления метаданных изображения автоматически отображаются:

1. В верхней части файла упражнения
2. Перед графиком прогресса
3. Обновляются при каждом открытии файла упражнения через Dataview

**Пример структуры файла упражнения:**

```markdown
# Сгибание рук с гантелями сидя

![[Pasted image 20251108104622.png|400]]

### 📊 График прогресса
[График Chart.js]

### 📋 История подходов
[Таблица подходов]
```

## Обновление существующих файлов

После обновления метаданных рекомендуется обновить файлы упражнений:

### Обновить все файлы
Команда: **"Обновить все файлы упражнений"**

### Обновить текущее упражнение
1. Откройте файл упражнения
2. Выполните команду: **"Обновить текущее упражнение"**

## Результаты обновления

После выполнения команды вы увидите уведомление:

```
✅ Метаданные обновлены
📊 Упражнений: +2 / -0
🖼️ Изображений: 15 (логов: 47)
```

Где:
- **+2 / -0** – добавлено и удалено упражнений
- **15** – количество обновленных изображений
- **47** – количество проверенных файлов логов

## Примечания

- Изображения собираются **только из файлов логов** в папке `Logs/`
- Если для упражнения найдено несколько изображений, используется **последнее найденное**
- Изображения не копируются, используются ссылки на существующие файлы
- При отсутствии изображения файл упражнения отображается только с графиком
