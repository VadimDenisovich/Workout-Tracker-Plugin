# Workout Tracker Plugin для Obsidian

Плагин для отслеживания тренировок в Obsidian с автоматическим созданием логов тренировок и управлением упражнениями.

## Функции

### 🏋️ Создание логов тренировок
- **Кнопка в левой панели**: Создание лога тренировки одним нажатием
- **Автоматическое определение шаблона**: По дням недели (понедельник, среда, пятница)
- **Выбор места тренировки** (спортзал или дома)
- **Отдельные файлы для домашних тренировок**: Каждая домашняя тренировка создает уникальный файл с timestamp (например, "2025-10-03-Home")
- **Умная проверка**: если лог в спортзале на сегодня уже существует, откроется существующий
- **Выбор шаблона для нетренировочных дней**: Если создаете лог в спортзале в нетренировочный день, можете выбрать нужный шаблон

### 💪 Управление упражнениями
- **Модальное окно упражнений**: Всплывающий список всех упражнений
- **Быстрый переход**: Клик по упражнению открывает файл со статистикой
- **Создание новых упражнений**: С автоматическим шаблоном для статистики
- **Удаление упражнений**: Кнопка удаления для каждого упражнения
- **Интеграция с Dataview**: Автоматическая подгрузка статистики по упражнениям

### 📁 Управление папками
- **Гибкая настройка папки**: Выбор любой папки для хранения данных о тренировках
- **Автоматическое создание структуры**: Создание подпапок Exercises, Logs, Templates
- **Навигация по папкам**: Удобный интерфейс для выбора папки в настройках
- **Автоматические шаблоны**: Создание шаблонов Monday, Wednesday, Friday, Home

## Структура папок

```
Workout/
├── Exercises/          # Файлы упражнений со статистикой
├── Logs/              # Логи тренировок по датам
└── Templates/         # Шаблоны тренировок
    ├── Monday.md      # Шаблон понедельника
    ├── Wednesday.md   # Шаблон среды
    ├── Friday.md      # Шаблон пятницы
    └── Home.md        # Шаблон домашней тренировки
```

## Использование

### Создание лога тренировки
1. Нажмите кнопку календаря в левой панели или используйте команду "Создать лог тренировки"
2. Выберите место тренировки (спортзал или дома)
3. Если выбран спортзал в нетренировочный день, выберите подходящий шаблон
4. Лог автоматически создастся и откроется для редактирования

### Управление упражнениями
1. Нажмите кнопку гантели в левой панели или используйте команду "Открыть упражнения"
2. Откроется модальное окно со списком упражнений
3. Для создания нового упражнения нажмите "Добавить упражнение"
4. Для удаления упражнения нажмите кнопку "−" рядом с названием
5. Для просмотра статистики нажмите на название упражнения - файл откроется в редакторе

### Настройка папки
1. Откройте настройки плагина (Settings → Community plugins → Workout Tracker)
2. Кликните на поле "Папка тренировок"
3. Откроется модальное окно с доступными папками
4. Выберите существующую папку или создайте новую нажав "+ Создать свою"
5. Для навигации по подпапкам кликайте на нужные папки
6. Структура папок создастся автоматически

## Шаблоны

Плагин создает следующие шаблоны:

### Шаблоны тренировок в спортзале
- **Monday**: Жим лежа, Приседания, Тяга штанги в наклоне
- **Wednesday**: Жим штанги стоя, Подтягивания, Отжимания на брусьях  
- **Friday**: Становая тяга, Жим лежа узким хватом, Подъем на бицепс

### Домашняя тренировка
- **Home**: Отжимания, Приседания без веса, Планка, Пресс

Все шаблоны автоматически заполняются текущей датой и местом тренировки.

## Интеграция с Dataview

Упражнения автоматически создаются с шаблоном Dataview для отслеживания прогресса:
- Таблица с историей выполнения
- График прогресса
- Автоматическая сортировка по дате

## Команды плагина

- `Создать лог тренировки` - Создание нового лога тренировки
- `Открыть упражнения` - Открытие модального окна со списком упражнений

## Настройки

- **Папка тренировок**: Поле для выбора основной папки для хранения данных. Кликните на поле для открытия селектора папок (по умолчанию: "Workout")

## Установка

1. Скопируйте файлы `main.js`, `manifest.json` и `styles.css` в папку `.obsidian/plugins/workout-tracker/`
2. Перезапустите Obsidian
3. Включите плагин в настройках Community plugins

## Требования

- Obsidian v0.15.0+
- Плагин Dataview (рекомендуется для полной функциональности статистики)
