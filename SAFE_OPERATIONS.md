# Безопасность операций плагина Workout Tracker

## 🛡️ Гарантии безопасности

### ✅ Плагин НИКОГДА не делает следующее:

1. **НЕ удаляет файлы пользователя**
   - Удаление происходит ТОЛЬКО через явный вызов `deleteExerciseFile()` из UI
   - При переносе папок удаляются только ПУСТЫЕ старые папки

2. **НЕ перезаписывает существующие файлы без причины**
   - Файлы упражнений создаются ТОЛЬКО если их нет
   - Шаблоны обновляются ТОЛЬКО если содержимое изменилось
   - Логи тренировок никогда не перезаписываются

3. **НЕ создаёт структуру папок при каждом запуске**
   - Структура создаётся ТОЛЬКО при первом запуске
   - Или при явной смене папки тренировок в настройках
   - Использует флаг `previousWorkoutFolder` для проверки

## 📋 Логика работы при запуске плагина

### 1. Инициализация (onload)
```typescript
// Проверка: нужно ли создавать структуру?
const needsStructureCreation = 
    !settings.previousWorkoutFolder || 
    settings.previousWorkoutFolder !== settings.workoutFolder;

if (needsStructureCreation) {
    // Создаём структуру только если:
    // - Первый запуск (previousWorkoutFolder пустой)
    // - Пользователь сменил папку в настройках
}
```

### 2. Создание структуры папок (createWorkoutStructure)
- ✅ Создаёт папки ТОЛЬКО если их нет (`ensureFolderExists`)
- ✅ Перемещает файлы ТОЛЬКО при смене папки (если `previousFolder !== workoutFolder`)
- ✅ Не трогает существующие файлы

### 3. Создание файлов шаблонов (createTemplateFiles)
- ✅ Сравнивает содержимое перед обновлением
- ✅ Обновляет ТОЛЬКО если шаблон изменился в коде
- ✅ Логирует все операции для отладки

### 4. Создание файлов упражнений (createExerciseFiles)
- ✅ Проверяет существование файла перед созданием
- ✅ Если файл существует - пропускает создание
- ✅ Не перезаписывает существующие файлы упражнений

### 5. Кэширование логов (rebuildCache)
- ✅ Запускается ПОСЛЕ полной загрузки хранилища (`onLayoutReady`)
- ✅ Только читает файлы, никогда не изменяет
- ✅ Удаляет из кэша ТОЛЬКО ссылки на несуществующие файлы

## 🔄 Обновление файлов

### Когда файлы обновляются?

1. **Файлы упражнений обновляются:**
   - При открытии файла упражнения (автообновление шаблона)
   - При изменении диапазона графика в настройках
   - При ручном вызове "Обновить файлы упражнений"

2. **Шаблоны обновляются:**
   - При изменении файла шаблона в папке Templates/
   - При нажатии "Обновить структуру" в настройках
   - ТОЛЬКО если содержимое отличается

3. **Логи тренировок:**
   - НИКОГДА не обновляются автоматически
   - Только создаются новые при запросе пользователя

## 🔍 Логирование

Все операции логируются для отладки:

```
[Main] ✅ Структура папок уже настроена, пропускаем создание
[FileManager] ⏭️ Файл упражнения уже существует, пропускаем: Жим лёжа
[FileManager] ⏭️ Шаблон не изменился, пропускаем: Monday.md
[ExerciseCache] ✅ Нет новых файлов для кэширования
```

## 🚨 Единственные операции удаления

1. **Удаление упражнения через UI:**
   - Требует явного подтверждения
   - Вызывает `deleteExerciseFile()`

2. **Удаление пустых папок при переносе:**
   - Происходит только при смене папки тренировок
   - Удаляются ТОЛЬКО пустые папки после переноса файлов

## 📝 Вывод

Плагин работает по принципу **"Не навреди"**:
- Минимальное вмешательство в существующие данные
- Максимальная безопасность операций
- Все изменения логируются
- Пользователь всегда контролирует процесс
