# Управление шаблонами

## Как работает система шаблонов

### Автоматическое обновление констант
При редактировании шаблона в Obsidian (файлы в папке `Templates/`), изменения **автоматически записываются** в константы `WORKOUT_TEMPLATES` в файле `src/templates.ts`.

Это означает:
- ✅ Вы редактируете `Monday.md` → изменения сразу попадают в код
- ✅ При пересоздании папки ваши изменения сохраняются
- ✅ При обновлении структуры используются актуальные версии шаблонов

## Кнопки в настройках

### 1. "Обновить структуру"
**Что делает:**
- Создаёт недостающие папки (Templates, Logs, Exercises)
- Создаёт файлы шаблонов из текущих констант в `templates.ts`
- Создаёт карточки упражнений

**Когда использовать:**
- После удаления папки тренировок
- Для создания недостающих файлов
- После добавления новых упражнений

**Важно:** Шаблоны берутся из констант кода, которые уже содержат ваши изменения!

### 2. "Сохранить текущие шаблоны как дефолтные"
**Что делает:**
- Читает текущее содержимое файлов шаблонов (`Monday.md`, `Wednesday.md`, и т.д.)
- Записывает их в константы `WORKOUT_TEMPLATES` в `src/templates.ts`

**Когда использовать:**
- Если вы хотите явно зафиксировать текущую версию шаблонов
- Перед сбросом, если хотите сохранить текущее состояние
- Для синхронизации после ручного редактирования (обычно не требуется, т.к. происходит автоматически)

### 3. "Сбросить все шаблоны" (Красная кнопка)
**Что делает:**
- Показывает инструкцию по восстановлению оригинальных шаблонов

**Как сбросить шаблоны к оригинальным:**

#### Вариант 1: Через Git
```bash
cd "/Users/vadim_denisovich/Documents/Obsidian test/testing/.obsidian/plugins/workout-tracker"
git checkout HEAD -- src/templates.ts
npm run build
```

#### Вариант 2: Через резервную копию
1. Найдите резервную копию `templates.ts` (если создавали)
2. Скопируйте её на место текущего файла
3. Пересоберите плагин: `npm run build`

#### Вариант 3: Вручную
1. Откройте `src/templates.ts`
2. Скопируйте оригинальные шаблоны из документации/git
3. Вставьте в константы `WORKOUT_TEMPLATES`
4. Пересоберите: `npm run build`

## Примеры использования

### Сценарий 1: Обычное редактирование
1. Открываете `Templates/Monday.md` в Obsidian
2. Меняете содержимое
3. Сохраняете → **Изменения автоматически попадают в `templates.ts`**
4. Всё готово! ✅

### Сценарий 2: Удалили папку тренировок
1. Папка удалена
2. Нажимаете "Обновить структуру"
3. Папка пересоздаётся с вашими шаблонами ✅

### Сценарий 3: Хотите вернуться к оригинальным шаблонам
1. Нажимаете "Сбросить все шаблоны"
2. Следуете инструкции (git checkout или копируете резервную копию)
3. Пересобираете плагин
4. Нажимаете "Обновить структуру"
5. Шаблоны восстановлены к оригинальным ✅

### Сценарий 4: Создаёте резервную копию текущих шаблонов
```bash
cp src/templates.ts src/templates.ts.backup-$(date +%Y%m%d)
```

## Техническая информация

### Где хранятся шаблоны?
- **Исходный код:** `src/templates.ts` → константы `WORKOUT_TEMPLATES`
- **Файлы в Obsidian:** `<папка_тренировок>/Templates/*.md`

### Как синхронизируются?
1. **Obsidian → Код:** При изменении файла в Obsidian → TemplateUpdater записывает в `templates.ts`
2. **Код → Obsidian:** При нажатии "Обновить структуру" → FileManager создаёт файлы из констант

### Что произойдёт при перезагрузке Obsidian?
- Плагин загрузится
- Шаблоны будут синхронизированы из файлов в код (если есть отличия)
- Всё работает как обычно ✅

## Устранение проблем

### Шаблоны не обновляются после редактирования
1. Проверьте консоль разработчика (Ctrl+Shift+I) на ошибки
2. Убедитесь, что файл `src/templates.ts` не защищён от записи
3. Попробуйте нажать "Сохранить текущие шаблоны как дефолтные"

