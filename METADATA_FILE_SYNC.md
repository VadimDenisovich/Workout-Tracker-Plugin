# Синхронизация exercise-metadata.json с файловой системой

## Обзор изменений

Реализована полная интеграция между `exercise-metadata.json` и файловой системой упражнений. Теперь добавление и удаление упражнений автоматически синхронизируется между метаданными и файлами.

## Реализованные функции

### 1. Синхронизация метаданных с файловой системой

**Файл**: `src/utils/exerciseMetadata.ts`

Добавлен метод `syncWithFileSystem()`:
- Сканирует папку `Exercises` 
- Добавляет новые упражнения из файловой системы в `exercise-metadata.json`
- Удаляет упражнения из метаданных, если соответствующие файлы отсутствуют
- Работает корректно на macOS и iOS (использует Obsidian Vault API)
- Возвращает статистику: количество добавленных и удаленных упражнений

**Пример использования**:
```typescript
const result = await this.exerciseMetadata.syncWithFileSystem(
  exercisesPath,
  this.settings.exerciseRegistry
);
console.log(`Добавлено: ${result.added}, Удалено: ${result.removed}`);
```

### 2. Создание отдельного файла упражнения

**Файл**: `src/utils/fileManager.ts`

Добавлен метод `createSingleExerciseFile()`:
- Создает файл для одного упражнения
- Использует правильный шаблон (с весом или без)
- Проверяет существование файла перед созданием
- Возвращает `true` если файл создан, `false` если уже существовал

**Пример использования**:
```typescript
const created = await this.fileManager.createSingleExerciseFile(
  workoutFolder,
  'Жим лежа',
  true // hasWeight
);
```

### 3. Обновленная команда обновления файлов

**Файл**: `main.ts`

Команда `refresh-exercise-files` теперь:
1. Пересобирает кэш упражнений
2. **Синхронизирует метаданные с файловой системой**
3. Обновляет реестр упражнений из метаданных
4. Обновляет все файлы упражнений
5. Показывает статистику изменений

**Использование**:
- Через палитру команд: `Обновить все файлы упражнений`
- Показывает уведомление с результатами синхронизации

### 4. Автоматическое создание/удаление файлов при регистрации упражнений

**Файл**: `main.ts`

#### `registerExercise()`:
1. Добавляет упражнение в реестр настроек
2. Добавляет в `exercise-metadata.json`
3. **Автоматически создает файл упражнения**

#### `unregisterExercise()`:
1. Удаляет упражнение из реестра настроек
2. Удаляет из `exercise-metadata.json`
3. **Автоматически удаляет файл упражнения**

## Кросс-платформенная совместимость

Все операции с файловой системой используют **Obsidian Vault API**, что обеспечивает:

✅ Корректную работу на macOS  
✅ Корректную работу на iOS  
✅ Корректную работу на Android  
✅ Безопасные операции с путями

**Ключевые принципы**:
- Используем `app.vault.adapter.read()` и `app.vault.adapter.write()`
- Используем `app.vault.getMarkdownFiles()` для поиска файлов
- Используем `app.vault.create()` и `app.vault.delete()` для операций с файлами
- Все пути относительные от корня хранилища

## Логирование

Все операции логируются в консоль разработчика:

- `[ExerciseMetadata]` - операции с метаданными
- `[FileManager]` - операции с файлами
- `[Main]` - операции на уровне плагина

**Примеры логов**:
```
[ExerciseMetadata] 🔄 Синхронизация с файловой системой...
[ExerciseMetadata] 📂 Путь к упражнениям: Workout/Exercises
[ExerciseMetadata] 📁 Найдено файлов упражнений: 45
[ExerciseMetadata] ➕ Добавлено новое упражнение: Приседания hasWeight: true
[ExerciseMetadata] ✅ Синхронизация завершена. Добавлено: 1 Удалено: 0
```
