# Исправление для мобильных устройств (v1.0.1)

## Проблема
На iPhone и других мобильных устройствах шаблоны DataViewJS не загружались корректно, из-за чего статистика упражнений не отображалась должным образом.

## Причина
Плагин пытался читать файлы шаблонов напрямую из файловой системы через Node.js API (`fs.readFile`), что работает только на десктопных версиях Obsidian. На мобильных устройствах:
- `FileSystemAdapter` недоступен
- Путь к директории плагина (`this.pluginDir`) не существует
- Попытки чтения через `fs.readFile` завершаются ошибкой

## Решение
Добавлена поддержка мобильных устройств через встроенные (embedded) шаблоны:

### 1. Метод `getExerciseTemplate()`
- **До:** Всегда пытался читать шаблоны из файловой системы
- **После:** 
  - Сначала пытается загрузить из ФС (для десктопа)
  - При ошибке использует встроенный шаблон `getEmbeddedExerciseTemplate()` (для мобильных)

### 2. Новый метод `getEmbeddedExerciseTemplate()`
Содержит полные встроенные шаблоны DataViewJS:
- `templateWithWeight` - для упражнений с весом
- `templateNoWeight` - для упражнений без веса (bodyweight)

Оба шаблона включают:
- ✅ Чтение данных из кэша
- ✅ Графики Chart.js (для упражнений с весом)
- ✅ Таблицы истории подходов
- ✅ Статистику последней тренировки
- ✅ Рекорды за все время
- ✅ Правильную замену `{{workoutFolder}}` и `{{exerciseName}}`

### 3. Метод `getTemplate()`
Также обновлен для корректной обработки ошибок на мобильных устройствах с fallback на импорт шаблонов.

## Технические детали

### Основные изменения в fileManager.ts:

```typescript
private async getExerciseTemplate(hasWeight: boolean = true): Promise<string> {
    try {
        // Попытка загрузки из ФС (десктоп)
        const dataviewjsPath = path.join(this.pluginDir, 'src', 'templates', templateFileName);
        let dataviewjsCode = await fs.readFile(dataviewjsPath, 'utf-8');
        // ... создание шаблона
    } catch (error) {
        // Fallback для мобильных - встроенные шаблоны
        return this.getEmbeddedExerciseTemplate(hasWeight, chartMin, chartMax);
    }
}
```

## Тестирование

### На iPhone:
1. Откройте любой файл упражнения (например, "Становая тяга классика (средний вес)")
2. Должны отобразиться:
   - 📊 График прогресса (если есть данные)
   - 📋 История подходов в виде таблицы
   - 📅 Статистика последней тренировки
   - 🏆 Рекорды за все время

### Признаки успешного исправления:
- ✅ Графики загружаются корректно
- ✅ Таблицы показывают данные
- ✅ Ссылки на логи работают
- ✅ Нет сообщений об ошибках

### Если проблемы остались:
1. Полностью закройте и переоткройте Obsidian на iPhone
2. Убедитесь, что плагин обновлен до версии 1.0.1
3. Проверьте консоль на наличие ошибок загрузки кэша

## Совместимость
