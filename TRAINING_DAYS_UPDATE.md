# Обновление функционала выбора дней тренировок

## Дата: 19 октября 2025

## Проблема

Ранее при изменении выбора дней тренировок в настройках плагин:
1. Вызывал `saveSettings()`, который пересоздавал всю структуру папок
2. Обновлял файлы шаблонов
3. Мог создавать ненужные файлы или удалять существующие

Кроме того, при первой инициализации создавались шаблоны только для выбранных дней, что могло создать проблемы при последующем добавлении новых дней.

## Решение

### 1. Отделение сохранения настроек от обновления файловой системы

**Изменено в:** `main.ts`

- Сделан публичным метод `persistSettings()` для сохранения настроек без обновления файлов
- При изменении выбора дней тренировок теперь вызывается `persistSettings()` вместо `saveSettings()`

```typescript
// Было:
await this.plugin.saveSettings();

// Стало:
await this.plugin.persistSettings();
```

### 2. Гарантированное создание всех шаблонов при инициализации

**Не требовалось изменений в:** `src/utils/fileManager.ts`

Функция `createTemplateFiles()` уже правильно работает:
- Перебирает все ключи из `TEMPLATE_FILES`
- Создает шаблоны для ВСЕХ дней недели (Monday-Sunday) + Home
- Не зависит от настройки `trainingDays`

- **НЕ** пересоздает структуру папок
- **НЕ** трогает файловую систему

### ✅ Первая инициализация плагина:
- Создает структуру папок
- Создает шаблоны для **ВСЕХ** дней недели (Monday-Sunday)
- Создает шаблон Home
- Создает файлы упражнений

### ✅ Модальное окно выбора тренировки:
- Показывает только выбранные дни из настроек
- Сортирует дни в правильном порядке (Пн-Вс)
- Использует русские названия дней

## Поведение

1. **При первом запуске плагина:**
   - Создаются папки: `/Workout/Templates`, `/Workout/Exercises`, `/Workout/Logs`
   - В папке Templates создаются файлы: `Monday.md`, `Tuesday.md`, ..., `Sunday.md`, `Home.md`
   - Создаются файлы упражнений в папке Exercises

2. **При изменении дней тренировок в настройках:**
   - Обновляется только настройка `trainingDays` в `data.json`
   - Файлы шаблонов остаются без изменений
   - Структура папок не пересоздается

3. **При выборе тренировки через ленту:**
   - Модальное окно показывает только выбранные дни
   - Все файлы шаблонов уже существуют
   - Нет необходимости создавать новые файлы

## Технические детали

### Методы сохранения настроек

```typescript
// persistSettings() - только сохранение в data.json
async persistSettings(): Promise<void> {
    await this.saveData(this.settings);
}

// saveSettings() - полное обновление (используется при смене папки)
async saveSettings() {
    const previousFolder = this.settings.previousWorkoutFolder;
    await this.persistSettings();
    
    await this.fileManager.createWorkoutStructure(
        this.settings.workoutFolder,
        previousFolder && previousFolder !== this.settings.workoutFolder ? previousFolder : undefined,
        this.settings.exerciseRegistry
    );
    
    this.settings.previousWorkoutFolder = this.settings.workoutFolder;
    await this.persistSettings();
}
```
