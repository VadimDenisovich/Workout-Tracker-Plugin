# Обновления Workout Tracker Plugin

## v1.0.1 - Исправление для мобильных устройств 🔧📱

### Исправлена проблема с шаблонами на iPhone/Android
- **Проблема**: На мобильных устройствах не загружались шаблоны DataViewJS, из-за чего статистика упражнений не отображалась
- **Решение**: Добавлены встроенные (embedded) шаблоны для мобильных устройств
- **Улучшено**: Автоматический fallback при невозможности чтения файлов из файловой системы
- **Совместимость**: Полная поддержка iOS, Android и Desktop

### Технические изменения
- Метод `getExerciseTemplate()` теперь использует встроенные шаблоны на мобильных устройствах
- Новый метод `getEmbeddedExerciseTemplate()` содержит полные шаблоны DataViewJS
- Улучшена обработка ошибок при загрузке шаблонов
- Шаблоны включают графики Chart.js, таблицы и статистику

## ✅ Реализованные изменения

### 🔄 Модальное окно вместо боковой панели
- **Список упражнений теперь всплывающий**: Больше не занимает место в боковой панели
- **Улучшенный дизайн**: Современный интерфейс с анимациями и hover-эффектами
- **Удобный размер**: Оптимальная ширина и высота модального окна
- **Прокрутка**: Поддержка большого количества упражнений с прокруткой

### 🏠 Отдельные файлы для домашних тренировок
- **Уникальные файлы**: Каждая домашняя тренировка создает отдельный файл
- **Формат с timestamp**: Файлы называются как "2025-10-03-Home"
- **Независимость от спортзала**: Домашние и спортивные тренировки не конфликтуют
- **Полная история**: Каждая домашняя тренировка сохраняется отдельно

### 🎯 Улучшенная навигация по упражнениям
- **Прямые переходы**: Клик по упражнению сразу открывает файл со статистикой
- **Автоматическое закрытие**: Модальное окно закрывается при переходе к упражнению
- **Быстрое создание**: Новые упражнения создаются и сразу открываются

- **Модальные окна**: Централизованное управление через модальные окна

## 📱 Новый пользовательский опыт

### Создание лога тренировки
1. Нажмите кнопку календаря 📅
2. Выберите место (спортзал/дома)
3. Для дома: создается файл "YYYY-MM-DD-Home"
4. Для спортзала: используется стандартная логика

### Работа с упражнениями
1. Нажмите кнопку гантели 🏋️
2. Откроется красивое модальное окно
3. Клик по упражнению → переход к файлу статистики
4. Кнопка "−" для удаления упражнения
