# Синхронизация шаблонов между устройствами (v1.1.0)

## Обзор изменений

Версия 1.1.0 добавляет полную синхронизацию шаблонов тренировок и настроек между всеми устройствами (Desktop и Mobile).

## Основные возможности

### 1. Сохранение всех шаблонов дней недели ✅

Теперь все шаблоны тренировок **автоматически сохраняются** при редактировании:
- ✅ Monday (Понедельник)
- ✅ Tuesday (Вторник)  
- ✅ Wednesday (Среда)
- ✅ Thursday (Четверг)
- ✅ Friday (Пятница)
- ✅ Saturday (Суббота)
- ✅ Sunday (Воскресенье)
- ✅ Home (Домашние тренировки)

**Как это работает:**
1. Редактируете шаблон в папке `Workout/Templates/Monday.md` (например)
2. Плагин автоматически:
   - Сохраняет изменения в код (`templates.ts`) на Desktop
   - Сохраняет переопределение в настройки (для Mobile)
   - Синхронизирует через Obsidian Sync/iCloud
3. На другом устройстве шаблон автоматически обновляется!

### 2. Экспериментальные шаблоны 🧪

Кастомные (экспериментальные) шаблоны теперь также **полностью синхронизируются**:

**Создание:**
1. Открыть модальное окно выбора места тренировки
2. Нажать "Эксперимент" → "Создать"
3. Ввести название шаблона
4. Редактировать созданный файл

**Редактирование:**
- Изменения автоматически сохраняются в настройки
- Синхронизируются между всеми устройствами
- Доступны на iPhone, Android, Desktop

**Удаление:**
- При удалении файла шаблона плагин автоматически очистит настройки

### 3. Синхронизация дней тренировок 📅

Настройка "Дни тренировок" теперь синхронизируется между устройствами:

**Проблема (было):**
- На iPhone выбрал Воскресенье
- На ноутбуке Воскресенье не отображается
- Приходилось настраивать на каждом устройстве отдельно

**Решение (стало):**
- Выбрал дни на одном устройстве → автоматически синхронизируется на все!
- Работает через Obsidian Sync, iCloud Drive, или любую другую синхронизацию

## Технические детали

### Архитектура сохранения

#### Desktop (Windows/Mac/Linux):
```
Редактирование шаблона
    ↓
Сохранение в templates.ts (файловая система)
    ↓
Сохранение в templateOverrides (настройки)
    ↓
Синхронизация data.json через Sync
```

#### Mobile (iOS/Android):
```
Загрузка data.json через Sync
    ↓
Чтение templateOverrides из настроек
    ↓
Использование встроенных шаблонов + переопределений
    ↓
При редактировании → сохранение в templateOverrides
    ↓
Синхронизация обратно
```

### Изменения в коде

#### 1. Новое поле в настройках
```typescript
export interface WorkoutTrackerSettings {
  // ... другие поля
  templateOverrides: TemplateOverrides; // Переопределения шаблонов
  trainingDays: WorkoutDay[]; // Дни тренировок
}
```

#### 2. Обновленный TemplateUpdater
```typescript
class TemplateUpdater {
  async updateTemplateInCode(templateName: string, newContent: string) {
    // 1. Сохранить в настройки (для синхронизации)
    settings.templateOverrides[key] = newContent;
    await saveSettings();
    
    // 2. Обновить исходный код (только на Desktop)
    await updateTemplateSource(key, newContent);
  }
}
```

#### 3. FileManager с приоритетом переопределений
```typescript
private async getTemplate(key: TemplateKey): Promise<string> {
  // Сначала проверяем переопределения (синхронизированные)
  if (settings.templateOverrides?.[key]) {
    return settings.templateOverrides[key];
  }
  
  // Потом пытаемся прочитать из файла (Desktop)
  // Fallback на встроенный шаблон
}
```

#### 4. Автоматическое отслеживание изменений
```typescript
this.registerEvent(
  this.app.vault.on('modify', async (file) => {
    if (file.path.startsWith(templatesPath)) {
      // Обновляем стандартный шаблон
      await templateUpdater.updateTemplateInCode(templateName, content);
      
      // Обновляем кастомный шаблон
      const customTemplate = settings.customTemplates.find(...);
      if (customTemplate) {
        customTemplate.content = content;
        await persistSettings();
      }
    }
  })
);
```

## Как использовать

### Настройка дней тренировок

1. **Настройки** → **Workout Tracker** → **Дни тренировок**
2. Кликните на нужные дни (ПН, ВТ, СР, ЧТ, ПТ, СБ, ВС)
3. Выбранные дни подсвечиваются
4. Автоматически сохраняется и синхронизируется

### Редактирование стандартных шаблонов

1. Откройте `Workout/Templates/Monday.md` (или любой другой)
2. Внесите изменения (добавьте упражнения, картинки, текст)
3. Сохраните файл (Ctrl+S / Cmd+S)
4. Плагин автоматически:
   - Обновит код на Desktop
   - Сохранит в настройки для Mobile
   - Покажет уведомление "Шаблон обновлен"

### Работа с экспериментальными шаблонами

#### Создание:
1. Ribbon → Иконка тренировки
2. Выберите день или "Эксперимент"
3. Если "Эксперимент" → "Создать"
4. Введите название (например, "HIIT Кардио")
5. Редактируйте созданный файл

#### Использование:
1. Ribbon → Иконка тренировки
2. Выберите "Эксперимент"
3. Выберите нужный шаблон из списка
4. Создастся файл тренировки с вашим шаблоном

#### Редактирование:
1. Откройте файл в `Workout/Templates/[Название].md`
2. Внесите изменения
3. Сохраните
4. Автоматически синхронизируется на все устройства

## Проверка синхронизации

### На Desktop:
1. Отредактируйте шаблон Monday.md
2. Проверьте в консоли (Ctrl+Shift+I):
   ```
   [TemplateUpdater] ✅ Переопределение шаблона сохранено в настройки
   [TemplateUpdater] ✅ Шаблон обновлён в исходном коде
   ```

### На Mobile:
1. Дождитесь синхронизации
2. Создайте новую тренировку для понедельника
3. Должен использоваться обновленный шаблон

### Проверка data.json:
```json
{
  "templateOverrides": {
    "MONDAY": "# Тренировка - Понедельник\n\n...",
    "SUNDAY": "# Тренировка - Воскресенье\n\n..."

      "content": "# Эксперимент - HIIT Кардио\n...",
      "type": "experiment"
    }
  ]
}
```

## Миграция существующих настроек

При первом запуске v1.1.0:

- Существующие `customTemplates` остаются без изменений

## Troubleshooting

### Шаблоны не синхронизируются

**Проблема:** Изменил шаблон на Desktop, не обновился на Mobile

**Решение:**
1. Проверьте, что Obsidian Sync/iCloud включен
2. Дождитесь завершения синхронизации
3. Полностью перезапустите Obsidian на Mobile
4. Проверьте консоль на Desktop - должно быть:
   ```
   [TemplateUpdater] ✅ Переопределение шаблона сохранено в настройки
   ```

### Дни тренировок сбрасываются

**Проблема:** Выбрал дни на iPhone, на ноутбуке снова дефолтные

**Решение:**
1. Убедитесь, что синхронизация включена
2. Проверьте `data.json` в `.obsidian/plugins/workout-tracker/`
3. Должно быть поле `"trainingDays": [...]`
4. Если его нет - выберите дни заново и дождитесь синхронизации

### Экспериментальный шаблон исчез

**Проблема:** Создал шаблон, но он пропал после перезапуска

**Решение:**
1. Проверьте, что файл существует в `Workout/Templates/`
2. Если файла нет - плагин автоматически удалит из настроек
3. Создайте шаблон заново
4. Убедитесь, что папка Templates синхронизируется
