# Исправление дубликатов упражнений (Unicode)

## Проблема

Упражнение "Жим гантелей лежа" не отображало все подходы из логов. При проверке кэша было обнаружено, что в `exercise-cache.json` существовало **два разных упражнения** с визуально одинаковым названием "Жим гантелей лежа".

### Причина

Проблема была вызвана разными формами представления буквы "й" в Unicode:

1. **NFD** (Canonical Decomposition): `и` + ` ̆` (U+0438 + U+0306) = "й"
2. **NFC** (Canonical Composition): `й` (U+0439)

При парсинге разных файлов логов использовались разные формы нормализации, что приводило к созданию дубликатов в кэше:
- Одна запись: `"Жим гантелей лежа"` (с й в форме NFC - U+0439)
- Вторая запись: `"Жим гантелей лежа"` (с й в форме NFD - U+0438 + U+0306)

### Пример hex-кодов

**Строка 2454** (NFD):
```
d0 b8 cc 86  =  и (d0 b8) + combining breve (cc 86)
```

**Строка 3153** (NFC):
```
d0 b5 d0 b9  =  е (d0 b5) + й (d0 b9)
```

## Решение

### 1. Нормализация при добавлении в кэш

В методе `addExerciseData` добавлена нормализация названия упражнения в форму **NFC**:

```typescript
private addExerciseData(
    exerciseName: string,
    date: string,
    sets: ExerciseSet[],
    hasWeight: boolean
): void {
    // ВАЖНО: Нормализуем название упражнения в NFC для избежания дубликатов
    const normalizedName = exerciseName.normalize('NFC').trim();
    
    if (!this.cache.exercises[normalizedName]) {
        this.cache.exercises[normalizedName] = {
            name: normalizedName,
            // ...
        };
    }
    // ...
}
```

### 2. Нормализация при парсинге логов

В методе `parseLogFile` добавлена нормализация после извлечения названия:

```typescript
// Извлекаем название упражнения
let exerciseText = line.replace(/^###\s*/, '').trim();
const linkMatch = exerciseText.match(/\[\[(?:Exercises\/)?([^\]|]+)(?:\|[^\]]+)?\]\]/);
if (linkMatch) {
    currentExercise = linkMatch[1].trim();
} else {
    currentExercise = exerciseText;
}

// ВАЖНО: Нормализуем название упражнения в NFC
currentExercise = currentExercise.normalize('NFC').trim();
```

### 3. Автоматическая дедупликация при загрузке

Добавлен метод `deduplicateExercises()`, который:
1. Находит все упражнения с одинаковыми нормализованными названиями
2. Объединяет их историю тренировок
3. Пересчитывает всю статистику (maxActualWeight, maxActualWorkingSet, allTimeMaxReps, allTimeMaxWeight)
4. Удаляет дубликаты и сохраняет только нормализованную версию

Метод вызывается автоматически при загрузке кэша:

```typescript
async load(): Promise<void> {
    // ...
    this.cache = JSON.parse(data);
    
    // Очищаем дубликаты после загрузки
    await this.deduplicateExercises();
    
    this.rebuildNormalizedNameMap();
    // ...
}
```

## Техническая справка

**Unicode нормализация:**
- **NFC** (Canonical Composition) - символы комбинируются в предкомпонованные формы
- **NFD** (Canonical Decomposition) - символы разбиваются на базовые + комбинирующие

**Почему NFC:**
- Более компактное представление
- Стандарт для большинства современных приложений
- Совместимость с файловыми системами
