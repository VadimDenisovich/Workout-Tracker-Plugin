# Обновление: Ссылки на упражнения

## Изменения

### 1. Обновлены шаблоны тренировок (templates.ts)

Все заголовки упражнений в шаблонах теперь содержат ссылки на файлы упражнений:

**Было:**
```markdown
### Жим гантелей лежа
```

**Стало:**
```markdown
### [[Exercises/Жим гантелей лежа|Жим гантелей лежа]]
```

Это изменение применено ко всем шаблонам:
- MONDAY
- WEDNESDAY
- FRIDAY
- HOME

### 2. Обновлен парсер упражнений (exerciseCache.ts)

Добавлена поддержка извлечения названия упражнения из ссылок в формате:
- `[[Exercises/Название|Название]]`
- `[[Exercises/Название]]`
- `[[Название]]`
- Обычный текст `Название` (для обратной совместимости)

**Изменения в коде:**
```typescript
// Извлекаем название упражнения, убирая ### и возможную ссылку [[название]]
let exerciseText = line.replace(/^###\s*/, '').trim();

// Проверяем, есть ли ссылка в формате [[Exercises/Название|Название]] или [[Название]]
const linkMatch = exerciseText.match(/\[\[(?:Exercises\/)?([^\]|]+)(?:\|[^\]]+)?\]\]/);
if (linkMatch) {
    currentExercise = linkMatch[1].trim();
} else {
    // Если нет ссылки, используем текст как есть
    currentExercise = exerciseText;
}
```

### 3. Обновлен шаблон страницы упражнения (EXERCISE_TEMPLATE)

Dataviewjs скрипт в шаблоне упражнения теперь ищет заголовки в обоих форматах:
- Со ссылкой: `### [[Exercises/Название|Название]]`
- Без ссылки: `### Название`

Это обеспечивает обратную совместимость с существующими логами.

## Преимущества

1. **Навигация**: Теперь можно кликнуть на название упражнения в логе и перейти к странице с прогрессом
2. **Обратная совместимость**: Старые логи без ссылок продолжают работать
3. **Автоматические бэклинки**: Obsidian автоматически показывает все тренировки с этим упражнением
4. **Граф связей**: Упражнения теперь видны в графе связей vault'а

## Как использовать

### Для новых тренировок
Просто создавайте новые логи из шаблонов - ссылки уже будут на месте.

### Для существующих тренировок (опционально)
Можете вручную добавить ссылки к заголовкам упражнений:

**Было:**
```markdown
### Жим гантелей лежа
Подход 1: 20 кг x 10 раз
```

**Стало:**
```markdown
### [[Exercises/Жим гантелей лежа|Жим гантелей лежа]]
Подход 1: 20 кг x 10 раз
```

Или оставьте как есть - плагин будет работать и без ссылок!
