# Чеклист тестирования изменений

## Подготовка
- [ ] Плагин собран: `npm run build` (успешно)
- [ ] Obsidian перезагружен

## Тест 1: Проверка первой инициализации

### Шаги:
1. [ ] Удалить папку тренировок (если существует)
2. [ ] Удалить настройки плагина: `.obsidian/plugins/workout-tracker/data.json`
3. [ ] Перезагрузить Obsidian
4. [ ] Включить плагин

### Ожидаемый результат:
- [ ] Создана папка `Workout/Templates/`
- [ ] В папке Templates есть ВСЕ файлы:
  - [ ] `Monday.md`
  - [ ] `Tuesday.md`
  - [ ] `Wednesday.md`
  - [ ] `Thursday.md`
  - [ ] `Friday.md`
  - [ ] `Saturday.md`
  - [ ] `Sunday.md`
  - [ ] `Home.md`

## Тест 2: Проверка изменения дней тренировок

### Шаги:
1. [ ] Открыть настройки плагина (Settings → Community plugins → Workout Tracker)
2. [ ] Запомнить текущее время изменения файлов в `Workout/Templates/` (например, через `ls -l`)
3. [ ] Изменить выбор дней тренировок (добавить/убрать день)
4. [ ] Проверить время изменения файлов в `Workout/Templates/`

### Ожидаемый результат:
- [ ] Файлы в `Workout/Templates/` НЕ изменились (время модификации то же)
- [ ] Настройка сохранена в `data.json`
- [ ] В консоли НЕТ логов о создании/обновлении шаблонов

### Команда для проверки:
```bash
# До изменения настроек
ls -l "/Users/vadim_denisovich/Documents/Obsidian test/testing/Workout/Templates/" > /tmp/before.txt

# После изменения настроек
ls -l "/Users/vadim_denisovich/Documents/Obsidian test/testing/Workout/Templates/" > /tmp/after.txt

# Сравнение
diff /tmp/before.txt /tmp/after.txt
# Должно быть пусто (нет изменений)
```

## Тест 3: Проверка модального окна выбора тренировки

### Шаги:
1. [ ] В настройках выбрать дни: Понедельник, Среда, Пятница
2. [ ] Нажать на иконку плагина в ленте (слева)
3. [ ] Проверить список дней в модальном окне

### Ожидаемый результат:
- [ ] В списке только: Понедельник, Среда, Пятница
- [ ] Дни в правильном порядке (не Пт, Пн, Ср)
- [ ] Нет Вторника, Четверга, Субботы, Воскресенья

### Дополнительная проверка:
1. [ ] Выбрать ВСЕ дни недели в настройках
2. [ ] Нажать на иконку в ленте
3. [ ] В списке должны быть все 7 дней

## Тест 4: Создание тренировки

### Шаги:
1. [ ] Выбрать день тренировки (например, Понедельник)
2. [ ] Проверить, что файл создан в `Workout/Logs/`
3. [ ] Открыть файл и проверить содержимое

### Ожидаемый результат:
- [ ] Файл создан с правильной датой
- [ ] Используется существующий шаблон из `Workout/Templates/Monday.md`
- [ ] Новый файл шаблона НЕ создан

## Тест 5: Смена папки тренировок

### Шаги:
1. [ ] В настройках изменить папку тренировок (например, с `Workout` на `MyWorkout`)
2. [ ] Проверить, что структура папок создана

### Ожидаемый результат:
- [ ] Старая папка осталась на месте (или перемещена)
- [ ] Новая папка создана
- [ ] В новой папке есть ВСЕ шаблоны (Monday-Sunday + Home)

## Проверка логов

### В консоли Obsidian (Ctrl+Shift+I / Cmd+Option+I):

При изменении дней тренировок НЕ должно быть:
```
[FileManager] ✅ Обновлён шаблон: Monday.md
[FileManager] ✅ Создан новый шаблон: Tuesday.md
```

При первой инициализации ДОЛЖНО быть:
```
[Main] 📁 Первый запуск или смена папки, создаём структуру...
[FileManager] ✅ Создан новый шаблон: Monday.md
[FileManager] ✅ Создан новый шаблон: Tuesday.md
...
```
