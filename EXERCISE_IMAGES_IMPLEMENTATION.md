# Обновление: Изображения упражнений

## Реализованные возможности

### 1. ✅ Сбор изображений из логов
- Автоматическое сканирование файлов логов тренировок
- Поиск изображений над заголовками упражнений (формат `### Название упражнения`)
- Сохранение ссылок на изображения в `exercise-metadata.json`

### 2. ✅ Обновление метаданных упражнений
- **Команда в палитре:** "Обновить метаданные упражнений (изображения и hasWeight)"
- **Кнопка в настройках:** "Обновить метаданные" в секции "Метаданные упражнений"
- Синхронизация списка упражнений с папкой `Exercises/`
- Определение `hasWeight` для каждого упражнения
- Сбор изображений из всех логов

### 3. ✅ Отображение изображений в файлах упражнений
- Изображения отображаются в верхней части файла упражнения
- Появляются перед графиком прогресса
- Работает для упражнений с весом и без веса
- Если изображения нет – отображается только график

## Формат данных

### exercise-metadata.json
```json
{
  "version": "1.0.0",
  "exercises": {
    "Название упражнения": {
      "name": "Название упражнения",
      "hasWeight": true,
      "imageLink": "![[image.png|400]]"
    }
  }
}
```

## Использование

### Первичная настройка
1. Убедитесь, что в логах тренировок изображения размещены над заголовками упражнений
2. Откройте Settings → Workout Tracker
3. Нажмите "Обновить метаданные" в секции "Метаданные упражнений"

### Регулярное использование
- При добавлении новых логов с изображениями периодически запускайте обновление метаданных
- Изображения будут автоматически отображаться при открытии файлов упражнений

## Технические детали

### Алгоритм поиска изображений
1. Плагин сканирует все файлы в папке `Logs/`
2. Ищет заголовки 3-го уровня с названиями упражнений: `### [[Название]]` или `### Название`
3. Проверяет до 3 строк выше заголовка на наличие изображения
4. Сохраняет полную строку с изображением (например, `![[image.png|400]]`)

### Регулярные выражения
- Поиск заголовка: `/^###\s+(?:\[\[)?([^\]\n]+?)(?:\]\])?\s*$/`
- Поиск изображения: `/^!\[\[([^\]]+)\]\]$/`

### Производительность
- Сканирование выполняется асинхронно
- Обновляются только изменённые данные
- Сохранение происходит один раз после завершения сканирования
