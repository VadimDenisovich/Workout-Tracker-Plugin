# Нормализация названий упражнений

## Проблема

Плагин не находил упражнения из-за различий в написании:
- **"Подъём"** vs **"Подъем"** (ё vs е)
- **"Подъём гантелей на дельты лежа"** vs **"Подъем гантелей на дельты"**

## Решение

Добавлена функция нормализации названий упражнений, которая:

1. **Приводит к нижнему регистру** — `"ПОДЪЁМ"` → `"подъём"`
2. **Заменяет "ё" на "е"** — `"подъём"` → `"подъем"`
3. **Удаляет лишние пробелы** — `"подъем  гантелей"` → `"подъем гантелей"`

## Технические детали

### Добавленные методы в `ExerciseCache`:

#### `normalizeExerciseName(name: string): string`
Приватный метод для нормализации названия упражнения.

```typescript
private normalizeExerciseName(name: string): string {
    return name
        .toLowerCase()
        .replace(/ё/g, 'е')
        .trim()
        .replace(/\s+/g, ' ');
}
```

#### `rebuildNormalizedNameMap(): void`
Приватный метод для обновления карты нормализованных имён после изменения кэша.

```typescript
private rebuildNormalizedNameMap(): void {
    this.normalizedNameMap.clear();
    for (const exerciseName of Object.keys(this.cache.exercises)) {
        const normalized = this.normalizeExerciseName(exerciseName);
        this.normalizedNameMap.set(normalized, exerciseName);
    }
}
```

### Обновлённый метод `getExerciseData`:

Теперь метод выполняет двухуровневый поиск:

1. **Точное совпадение** — сначала ищет упражнение с точным названием
2. **Нормализованный поиск** — если не найдено, ищет через нормализацию

```typescript
getExerciseData(exerciseName: string): ExerciseData | null {
    // Сначала пытаемся найти точное совпадение
    if (this.cache.exercises[exerciseName]) {
        return this.cache.exercises[exerciseName];
    }
    
    // Если не нашли, ищем через нормализованное имя
    const normalized = this.normalizeExerciseName(exerciseName);
    const originalName = this.normalizedNameMap.get(normalized);
    
    if (originalName && this.cache.exercises[originalName]) {
        console.log('[ExerciseCache] Найдено упражнение через нормализацию:', 
                    exerciseName, '->', originalName);
        return this.cache.exercises[originalName];
    }
    
    return null;
}
```

## Изменённые методы

Следующие методы теперь вызывают `rebuildNormalizedNameMap()` для обновления карты:

- `load()` — после загрузки кэша из файла
- `rebuildCache()` — после добавления новых упражнений
- `recacheFile()` — после пересчёта кэша для файла
- `clearCache()` — очистка карты вместе с кэшем

## Примеры использования

### До изменений:
```typescript
// В кэше: "Подъем гантелей на дельты"
// В шаблоне: "Подъём гантелей на дельты лежа"
cache.getExerciseData("Подъём гантелей на дельты лежа"); // ❌ null
```

### После изменений:
```typescript
// В кэше: "Подъем гантелей на дельты"
// В шаблоне: "Подъём гантелей на дельты"
cache.getExerciseData("Подъём гантелей на дельты"); // ✅ находит "Подъем гантелей на дельты"
```

## Важные замечания

1. **Нормализация не изменяет данные в кэше** — оригинальные названия сохраняются как есть
2. **Поиск сначала точный, потом нормализованный** — это обеспечивает максимальную совместимость
3. **Карта обновляется автоматически** — при любых изменениях кэша
4. **Логирование** — при нахождении через нормализацию выводится сообщение в консоль
